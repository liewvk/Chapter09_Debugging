# Chapter 09: Debugging

A Python project demonstrating debugging techniques, tools, and best practices.

## Overview

This repository contains examples and exercises for debugging Python code, including:
- Using debuggers (pdb, IDE debuggers)
- Logging and log analysis
- Error handling and exception debugging
- Code inspection and profiling
- Debugging strategies and workflows

## Features

- **Interactive Debugging**: Examples using Python's built-in debugger (pdb)
- **Logging**: Comprehensive logging strategies and configuration
- **Error Tracking**: Techniques for identifying and fixing bugs
- **Code Analysis**: Tools and methods for analyzing code behavior
- **Testing**: Debugging through unit tests and assertions
- **Profiling**: Performance debugging and optimization

## Getting Started

### Prerequisites

- Python 3.x

### Installation

1. Clone the repository:
```bash
git clone https://github.com/liewvk/Chapter09_Debugging.git
```

2. Navigate to the project directory:
```bash
cd Chapter09_Debugging
```

## Usage

Run Python scripts to explore debugging techniques:
```bash
python script_name.py
```

### Using the Debugger

Enter the Python debugger interactively:
```bash
python -m pdb script_name.py
```

## Debugging Tips

1. **Understand the Problem**: Reproduce the error consistently
2. **Isolate the Issue**: Use binary search to narrow down the problem
3. **Use Logging**: Add strategic log statements before using a debugger
4. **Test Your Fix**: Verify the solution with tests
5. **Learn from Mistakes**: Document common errors
